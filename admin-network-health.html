AgentsNetworking API (GET /v2.0/agents), admin only. Not alive → critical. Ceilometer has no Neutron service metric (admin doc, design note 2).
Trafficsum(rate(ceilometer_network_{incoming,outgoing}_bytes[5m]))
Quiet routerInterfaces behind the router (Neutron ports, matched to metrics by tap name) whose inbound packets fell below 10% of the same time yesterday. Only judged when usual traffic is at least 0.5 packets/s per interface.
Platform verdictRouters of two or more projects going quiet at the same time, or an agent down, → probably the platform. One project only → probably that project's setup.
Drops / errorsrate(ceilometer_network_*_packets_{drop,error}[5m]), each metric named explicitly (Aetos rejects __name__ regex selectors).
