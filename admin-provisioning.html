How this page is calculated (click to expand)

ItemSource / rule
Boot timeceilometer_compute_instance_booting_time (seconds, one notification per boot). Its vm_instance label is the real host name, unlike the other instance metrics.
Counting bootsPrometheus keeps scraping the last value for a while (10–18 identical samples per boot on the VM), so boots are counted per instance and value, not per sample: last_over_time(…[range]) by resource, plus changes() for rebuilds.
Slow hostAlways judged on the last 24 h, whatever the range: at least 3 boots and a median above 2× the cloud's 24 h median → Slow; above 1.5× → Slower. A longer range would hide a host that turned slow recently behind its older, normal boots.
Slowest / p95With fewer than 20 boots, the page shows the slowest boot instead of a 95th percentile.
Failed buildsCompute API: instances in ERROR whose creation falls in the range, with the instance fault. A failed build has no boot time sample.
