How this page is calculated (click to expand)

ResourceQuery (per project; per instance drops the sum by)
CPUtopk(10, sum by (project) (rate(ceilometer_cpu{…}[5m])) / 1e9): cores in use. Allocated: sum by (project) (ceilometer_vcpus{…})
Memorysum by (project) (ceilometer_memory_usage{…}). Allocated: ceilometer_memory (flavor RAM)
Disk I/Orate(ceilometer_disk_device_read_bytes[5m]) + …write_bytes
Networkrate(ceilometer_network_incoming_bytes[5m]) + …outgoing_bytes

{…} is resource_name=~".+:instance-.+": only polled samples, so instances aren't counted twice. Metrics carry project IDs; names come from Keystone (cached). "Allocated" counts running instances only: there is no hypervisor capacity in Ceilometer, so the share is of what is in use, not of the cloud's size (Placement would be needed for that).
