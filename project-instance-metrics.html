How this page is calculated (click to expand)

ItemSource / query / rule
Instance listCompute API: the instances of the current project. The page is opened from the Compute, Network or Usage pages.
CPU usedrate(ceilometer_cpu{resource="<uuid>"}[5m]) / 1e9: vCPUs busy. Dashed line: ceilometer_vcpus.
CPU waitrate(ceilometer_cpu_delay[5m]) / 1e9 ÷ vCPUs. Warning 5%, critical 20%, as in Instance Health.
Memory usedceilometer_memory_usage against ceilometer_memory (flavor RAM). Swap: rate(ceilometer_memory_swap_{in,out}[5m]).
Disk throughputrate(ceilometer_disk_device_{read,write}_bytes[5m]), summed over the instance's disks.
Disk latencyrate(…_write_latency[5m]) ÷ rate(…_write_requests[5m]). Empty when there were no writes.
Network trafficrate(ceilometer_network_{incoming,outgoing}_bytes[5m]), summed over the instance's interfaces.
Time seriesAetos has no query_range: each chart is an instant query with a subquery, e.g. (…)[12h:5m].

Only polled samples are used (resource_name ending in :instance-<uuid>), so nothing is counted twice. Aetos limits every query to the current project.
