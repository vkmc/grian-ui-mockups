Period coveredFrom the later of: start of the month, or now − retention. Days before that are shown as not kept, never as zero.

Retention. This cloud keeps metrics for 15 days (Prometheus default; DevStack doesn't change it). Grian can't read the retention for project users: the Aetos status endpoint that reports it is limited to admins and services (telemetry:status), so the value comes from an operator setting (GRIAN_PLUGIN['metrics_retention_days']). A monthly report is complete only if retention is longer than a month, or if the operator keeps daily totals with recording rules.

Only polled samples are used (resource_name ending in :instance-<uuid>). Ceilometer also emits a notification sample per instance with a different resource_name; summing both would count every instance twice. Instances that never ran (ERROR) have no metrics and appear only in the note below the table. Long periods depend on the Prometheus retention set by your operator.
